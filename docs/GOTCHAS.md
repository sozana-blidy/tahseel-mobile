# Gotchas

- 2026-11-15: PL/pgSQL — `if func_returning_row(x) is not null` is FALSE when any column is null (e.g. agent with no phone). Test `(func(x)).id is not null`.
- 2026-11-15: PL/pgSQL — a variable named like a column (`code`) makes `where code = code` ambiguous. Prefix variables `v_`.
- 2026-11-15: `to_char(numeric, 'FM999.##')` leaves a trailing dot for whole numbers ("10."). Use `trim_scale(x)::text`.
- 2026-11-15: Supabase "Confirm email" must be OFF or agent sign-up stalls (fake `@agents.tahseel.app` emails).
- 2026-11-15: `supabase/tests/supabase_emulation.sql` is test-only — never run it on Supabase.
- 2026-11-15: Import is refused once any invoice exists (protects payment history). Import first, then open the month.
- 2026-11-15: Per-invoice commission uses Asia/Damascus month of the payment that completed the invoice.
- 2026-11-15: Supabase / FCM reachability from Syrian mobile networks is unverified — test on real agent phones.
- 2026-11-15: `npx expo install` needs api.expo.dev; when blocked, take versions from `node_modules/expo/bundledNativeModules.json` and `pnpm add pkg@version`.
- 2026-11-15: `.npmrc` has `node-linker=hoisted` — Metro + pnpm on Windows is most reliable hoisted.
- 2026-11-15: RTL — release builds forced by `expo-localization` plugin (`forcesRTL`). Expo Go needs one app restart after first launch.
- 2026-11-15: RTL — never set `textAlign: "left"/"right"` on Text/TextInput: Android swaps them under RTL. Leave default (start).
- 2026-11-15: Latin text alone in a Text line (usernames) aligns LEFT on Android. Put it inside an Arabic line; join parts with " ‏· " (RLM) to keep order.
- 2026-11-15: Agent login email = `<username>@EXPO_PUBLIC_AGENT_EMAIL_DOMAIN`. If Supabase rejects the domain, set a domain you own (DB only checks the part before @).
- 2026-11-15: Offline outbox key is per user (`tahseel.outbox.v1:<uid>`); sign-out keeps unsent payments for that user's next login.
- 2026-11-15: Expo Router — `Tabs` from "expo-router" is deprecated; import from "expo-router/js-tabs".
- 2026-11-15: Two routes resolving to the same URL (e.g. manager/index.tsx and manager/(tabs)/index.tsx) break the router — delete the old file.
- 2026-11-15: Auth — never reload the profile from the session captured at render time; read `supabase.auth.getSession()` (right after sign-up the rendered session is stale).
- 2026-11-15: Dates/codes inside Arabic lines: wrap with LRI/PDI (`ltr()` in ui/parts.tsx) or they render as 15-11-2026.
- 2026-11-15: Migrations are append-only once shared: fixes go in a new file (0004), never edit 0001–0003.
- 2026-11-15: Excel — cdn.sheetjs.com is unreachable from the build sandbox and npm `xlsx` (0.18.5) is outdated; we use our own reader/writer (`src/lib/xlsx.ts`, fflate). Merged cells repeat the top-left value (same as ExcelJS).
- 2026-11-15: Import is refused once any invoice exists. Clear test data first: `supabase/scripts/reset_test_data.sql`.
- 2026-11-15: The real workbook is never committed (`*.xlsx` ignored). Tests read it from `TAHSEEL_REAL_XLSX`.
- 2026-11-15: `/android` is generated by `expo prebuild --clean` — never edit it by hand; native changes go in `plugins/`.
- 2026-11-15: Release key lives outside the repo (`%USERPROFILE%\.gradle\gradle.properties`). Lose it = phones must reinstall. Back it up.
- 2026-11-15: Every update needs a higher `android.versionCode` in app.json, signed with the same key.
- 2026-11-15: Expo Go — DocumentPicker with copyToCacheDirectory:true puts the file in Expo Go's own cache, outside the app sandbox ("isn't readable"). Use copyToCacheDirectory:false and read the content:// uri (legacy readAsStringAsync).
- 2026-11-15: React — never put a callback prop in an effect's deps when callers create it inline (useOutbox re-subscribed every render → 2,453 renders/4 s). Store it in a ref; make hook-returned functions stable with useCallback. Production builds hide the 'Maximum update depth' warning — measure commits instead.
- 2026-11-15: Migration 0005 must run in Supabase BEFORE installing the M5 app (daily_collections/day_payments; area_subscribers gained paid_via → dropped and recreated).
- 2026-11-15: Reminders are LOCAL scheduled notifications (expo-notifications): free, no Firebase, work on Syrian networks — but the text is fixed (no live amounts). Rescheduled at every sign-in, cancelled at sign-out. Not available on web (guarded).
- 2026-11-15: Names display as three parts via lib/names.ts (first + father + family; compound first names kept together). Stored fields are unchanged.
- 2026-11-15: WhatsApp Business Platform (API) does not serve Syria (+963) — automated reminders by WhatsApp API are impossible; use wa.me links (manual send) instead.
- 2026-11-16: Native build "Filename longer than 260 characters" (safe-area-context/screens/gesture-handler ~290–340 chars) — SDK CMake 3.22.1's ninja 1.10 ignores LongPathsEnabled. Fix: CMake 4.0.2 (ninja 1.12) pinned by `plugins/withCmakeVersion.js`. Shorter project paths are not enough.
- 2026-11-16: Setting `cmake.version` at the END of android/build.gradle fails ("It is too late to set version") — `expo-root-project` evaluates :app when applied. The plugin inserts its block before that line.
- 2026-11-16: `sdkmanager` CLI is blocked by Smart App Control (nio.dll) — install SDK components from the Android Studio UI.
- 2026-11-16: `prebuild --clean` EBUSY on `android` = a terminal still `cd`'d into it (or a Gradle daemon). Leave the folder / `gradlew --stop`.
- 2026-11-16: After moving the repo folder, pnpm wants to recreate node_modules (stored virtualStoreDir path). Run `pnpm install` in a normal terminal and accept.
- 2026-11-16: Honor phones (and other aggressive OEMs) must disable battery optimization for Tahseel (Settings → Battery → App launch → Tahseel → Manage manually, all on), or the 22:00 notification and its background refresh are delayed or skipped.
- 2026-11-16: Damascus time in the app = fixed UTC+3 (`src/lib/damascus.ts`). Syria has had no DST since Oct 2022; avoids relying on Hermes/phone time-zone data. If Syria ever changes its clock, change it there (the DB uses 'Asia/Damascus').
- 2026-11-16: Android notification channel settings (sound, importance) are frozen once created — change them only by creating a NEW channel id (now `tahseel-alerts-v2`) and deleting the old one.
- 2026-11-16: Background tasks (expo-task-manager) must be defined at bundle load — a headless run renders no route, so `_layout` never loads. They are imported from the app entry `index.js` (package.json "main"), before `expo-router/entry`.
- 2026-11-16: No partial payments since migration 0006: `manager_record_payment` accepts only the full remaining amount; legacy part-paid invoices show as «غير مدفوع» with only the remainder due.
- 2026-11-16: pnpm (hoisted) prints "Packages: +11 -48" when adding 2 packages — that is node_modules being re-hoisted, not dependencies removed. Compare the lockfile `packages:` list to be sure.
- 2026-11-16: R8 strips WorkDatabase_Impl constructor (WorkManager via expo-background-task) → crash at launch; keep rules via extraProguardRules.
- 2026-11-16: Supabase anonymous (guest) users get the `authenticated` role — only the JWT claim `is_anonymous` tells them apart. Never grant by role alone; guest functions check `auth.jwt()->>'is_anonymous'` AND an unlocked guest session.
- 2026-11-16: A PL/pgSQL `raise` rolls back everything in that call — `guest_unlock` RETURNS {ok:false} on a wrong code so the failed attempt (rate limit) is kept.
- 2026-11-16: Supabase CAPTCHA (Attack Protection) applies to ALL sign-ins — enabling it without app support blocks manager/agent logins. Use the anonymous sign-in rate limit + guest code instead.
- 2026-11-16: Edge Function `index.ts` is Deno (npm:/jsr: imports) → excluded from `tsc` in tsconfig.json; its pure logic lives in `logic.ts` (type-checked + vitest).
- 2026-11-16: Paying a carried (deferred) invoice writes TWO payment rows: client_key and client_key + ':carried'. Idempotency checks both keys.
- 2026-11-16: Late-payment DB tests use months relative to now() (payments are stamped with now()), not the fixed test month.
